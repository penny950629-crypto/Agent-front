# 前端示範原型

## 啟動

```powershell
npm ci
npm run dev
```

登入帳號為 `D1001`（醫師）或 `admin`（系統管理員），兩者的初始示範密碼皆為 `demo123`。管理員可新增、編輯或停用醫師帳號；新增的醫師可使用員工編號和初始示範密碼登入。

## 已涵蓋流程

- 醫師登入、登出、值班區域、個人資料、深淺色主題與密碼變更。
- 病患清單、3 小時惡化風險排序、轉歸預測及處置建議檢視。
- 完全採納、部分採納或未採納回饋、實際轉歸與處置紀錄編輯。
- 依姓名／病歷號和日期區間查詢歷史紀錄，以及依檢傷分類和回饋計算統計看板。

若預測 API 無法連線，系統會顯示去識別化示範資料。資料以目前瀏覽器的 `localStorage`／`sessionStorage` 保存，適合展示流程，不具備正式帳號驗證或跨使用者資料儲存能力。此原型不可輸入真實帳密或病患資料，亦不可用於臨床決策。正式環境需由受控後端驗證身分與權限，並透過後端存取合規的病歷及已驗證模型。
